# Minimalist E-commerce website

- A minimalist e-commerce website design that emphasizes simplicity and elegance.
- Focused on providing a smooth and effortless shopping experience, it reduces clutter with clean visuals, subtle transitions, and intuitive navigation.
- This design keeps the user journey fluid and unobtrusive, ensuring a calm, distraction-free interface that showcases products with clarity and style.
- To fetch the product lists and details, we used DummyJSON API. 
- User login and cart details are saved in Firebase.
